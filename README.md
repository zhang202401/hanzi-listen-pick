# 汉字幸存者 · 听音选字 🔊📱（幼儿园识字版）

幸存者类识字游戏：小朋友操控小金豆躲避小怪兽，全程**只听只点、不开麦克风**——
升级时语音读字、孩子**听音点字**作答；技能升级直接**点卡片**，没有任何"喊字跟读"环节。

## 玩法（给家长看）

| 环节 | 玩法 | 学什么 |
|---|---|---|
| 🕹 移动 | 手机按住拖动 / 电脑 WASD·方向键，Shift 冲刺 | 武器自动攻击，孩子专注走位 |
| 🔊 听音选字 | 每 2 次升级出现一次：语音读"哪个是大字？大象的大。"，4 个大字里点对即可（点字可先听音，再点确认） | 音→形 对应 |
| 👆 点卡升级 | 其余升级出现 3 张汉字技能卡（大/水/山/木/金…），点一张即升级（键盘 1/2/3 也行） | 认字复习 |
| 🛡 Boss 识字护盾 | 语音读字，跑到正确的字气泡上撞碎护盾 | 听觉辨识 + 反应 |

- 技能与汉字含义同构：**水**=回血、**山**=护盾、**风**=加速、**金**=吸经验、**月**=环刃、**电**=闪电链、**炸**=榴弹、**冰**=减速……玩技能 = 体验字义
- 课程 60 个学前基础字，随等级逐步解锁（开局 6 个字，从 0 开始）
- 答错的字进错字本，游戏中间隔重现；家长设置里可导出学字档案
- 8 分钟生存胜利，之后进入无尽模式

## 运行

```bash
cd 听音选字
npm install
npm run dev      # 手机电脑同一 WiFi，扫控制台地址即可真机试玩
npm run build    # 产出 dist/，任意静态服务器可部署
```

## 语音说明

- **语音朗读**（出题/鼓励）：浏览器内置 Web Speech TTS，所有现代浏览器可用，全程**不需要麦克风权限**
- 想要更自然的声音：Edge 自带"晓晓"等在线音色最自然，可在家长设置里挑选

## 目录结构

```
src/
  data/chars.js      # 60 字课程库（拼音/例词/emoji/字形提示）+ 出题器
  data/skills.js     # 8 主技能字卡（大小水山风火日地）+ 6 被动字卡（木金田石星足）+ 心
  data/weapons.js    # 10 武器字卡（月电炸光箭花蛇回冰雷）
  systems/voice.js   # 仅 TTS 朗读（无语音识别/麦克风）
  systems/quiz.js    # 听音选字浮层（点字听音、答错语音教学、揭晓拼音）
  systems/profile.js # 学字档案：每字统计/错字本/自适应出题
  scenes/GameScene.js  # 战斗主场景（继承数学幸存者全量防卡死修复）
  scenes/UIScene.js    # HUD + 点选升级卡片界面
```

基于《数学幸存者》引擎（福建省中职概率统计版）改造，战斗/升级/防卡死逻辑经过 30 分钟自动化耐久验证。
